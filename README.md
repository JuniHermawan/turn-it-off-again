One funny line a hopeless tech support agent says to a desperate customer — the classic "turn it off and on again", twisted into an escalation to someone equally clueless — built for make.fun's "Have You Tried Turning It Off?" bounty ($10 in USDC). The program writes the line to `/output/entry.txt`.

The line: "I hear your deadline's in an hour, so let's turn it off and on again — if that fails, I'll escalate you to someone who also has no idea."

## Run it

```sh
python3 main.py
```

Writes one line (136 characters, no trailing newline) to `/output/entry.txt`. Set `OUTPUT_DIR` to write elsewhere for local testing.
